# Step2 认可资产续页单位修复

## 原因与原文依据

用户截图的认可资产跨表冲突，对应弘康人寿 2026Q1 报告：物理页 9 的认可资产与第 24 页认可资产表合计均为 95,047,859,471.59 元。第 22 页表头明确“单位：元”，第 23、24 页没有重复单位。标准金额应为 9,504,785.947159 万元。

旧实现为控制超时将 S03 拆成单页请求，却没有为续页保留表头单位上下文。模型误填万元或单位缺失时，旧换算函数还可能将未换算数值直接挂上目标单位。截图本身未显示完整原始模型回复，不能断言本次属于哪一种单位误填；两条代码路径均已修复。

## 修改

- 保持逐页提取，只在续页请求附加同表单位来源页作为上下文。复用已缓存图片，不新增模型调用，不重新渲染整份 PDF；默认最多两张图，遵守显式配置的请求页数上限。
- 上下文页不是数据页：明确限制模型只提取当前页，过滤误返回的上下文页金额。
- 超时重试仅处理失败页，但保留原始完整表范围和单位来源页。
- 原生 PDF 读取本表明确“单位”标签作为证据，连续同表续页可继承；碰到不同表、间断页或多种冲突单位时停止继承。支持同页多表，不把上一张表的单位套给下一张表。
- 扫描 PDF 同样传递图片上下文，要求模型单独返回表头单位、来源物理页及单位原文。引用页必须在实际输入图片中，单位必须与所引原文一致。
- 明确的原值单位、行列单位优先；不凭跨表数字倍数猜测单位。源单位缺失或不受支持时，非零金额不再直接冒充标准金额，而是留待核验。
- 保留原始金额；使用表头纠正模型单位时在证据列记录来源页、单位原文和模型原单位。
- 未调整跨表一致性容差，也未修改实际金额；真实数字差异仍会阻断。

## 测试与使用

新增 13 项测试，包含弘康原 PDF 单位继承、错误单位修正、模拟扫描版单位证据、续页重试、零值、单位变更、同页多表、上下文串值隔离，以及真实金额差异仍然失败。原有爱心人寿超时隔离测试保留并更新图片上下文断言。

本次测试使用本地 PDF 与受控模型回复，没有线上模型实测。刷新/重启系统后重新执行 Step2 即可使用修复；无需重新定位已正确确认的页码。旧会话或已下载 Excel 不会在无 PDF 来源证据时被自动按倍数改值。
