## 原因与通用修复

旧流程将各批次模型命中的页码直接并集，未区分主表、续表、汇总引用；多页共用证据和最高置信度也掩盖了局部误判。经营指标的定位定义缺少产品、品质分项的明确覆盖要求。

- 模型逐页返回物理页码、可见标题、简短证据、来源角色及置信度。
- 主表与续表进入提取范围，汇总、变动分析和目录保留为辅助候选，不自动混入。
- 对标题与模型角色矛盾的典型情况做确定性过滤；不要求出现 S02/S03/S05 字样。
- 允许一页同时包含多个目标，不因另一表标题而排除同页数据；不直接扩展相邻页。
- 经营指标增加主要、效益、规模/渠道、前五位产品、品质分组。若已命中经营数据但未确认产品/品质范围，仅用缓存拼图复核末尾所在批次及必要的下一批次，最多两次额外请求，每次仍为一张拼图、最多六页、90 秒、并行不超过两个。
- 局部复核失败保留首轮成功结果并提示人工核对；局部响应不得修改其他目标。报告可能确实没有某分项，不能把未确认直接当成已披露或无误。
- 不依赖文字层，扫描版仍走相同视觉流程。所有页码仍可人工更改并确认。

## 展示

各目标页码输入框下仅保留一个默认折叠的“查看定位证据 / 目录 / 标题 / 结构候选来源”，包含自动页码、证据、候选来源和采用候选操作。需人工核对时外部仅显示简短提示；右侧 PDF 预览不变。

## 验证与限制

新增 11 项测试，覆盖截图错误、来源角色、同页多表、续页、物理页边界、置信度、局部超时、真实 PDF 渲染与 Streamlit 折叠及候选应用回调。全套 449 项本地测试通过。

定位测试使用受控模拟模型回复，真实 PDF 页码另经人工视觉核验；本次未调用线上模型，不能将这些结果当作线上模型准确率或跨公司盲测成绩。模型仍可能看错标题，必须保留证据核验与人工确认。

更新后重新运行 Step1；已有会话中的旧定位结果不会自动覆盖，以免丢失人工修改。
