# S05 量化风险最低资本：来源行语义防错

## 问题与来源

用户提供的财信人寿截图中，源表有两个独立指标：

| 指标编码 | 原始行 | 本期期末金额（元） | 标准金额（万元） |
| --- | --- | ---: | ---: |
| QUANT_RISK_CAPITAL | 1：量化风险最低资本 | 4,468,722,380.78 | 446,872.238078 |
| QUANT_RISK_CAPITAL_BEFORE_FACTOR | 1*：量化风险最低资本（未考虑特征系数前） | 4,703,918,295.56 | 470,391.829556 |

此前模型把 1* 的金额和完整行标签同时返回给两个编码。已有提示要求区分，但候选选择主要依赖期间、状态和置信度，确定性校验没有检验编码对应的来源行含义。这属于来源错配，不是精度问题。

## 修复

- 提取提示及轻量目标卡明确每个编码的独立匹配规则，保留括号限定语和实际行次。
- 候选结果及跨页合并优先选择来源语义正确的记录，不能让高置信度的错行覆盖正确行。
- 新增“来源指标语义”校验，支持未考虑/不考虑特征系数、考虑特征系数前、调整前等表述，行 1* 作辅助；不得只因两个值相等就判错，实际可能相等。
- 错配触发有明确原因的定向重提。已有明确来源错配时，先修复该行，不因它产生的公式/跨表失败连带重提正确来源；其他无关失败保持原有处理。
- 重试仍错则保留原始金额、标签与失败状态，阻断 Step3，不能通过放宽容差、修改金额或标成未披露来放行。
- 既有 Step2 会话及上传的旧完整工作簿重新校验来源语义；不会猜测或自动替换缺少正确来源证据的金额。旧错配结果需要重新提取。
- 公司无关规则，未把财信金额或页码写入生产逻辑。

## 验证范围

`tests/test_quant_risk_semantics.py` 覆盖正向/反向错配、不同括号和限定语、行次、候选优先级、只重提错误指标、永久错配阻断、两个指标合法同值、旧工作簿及缺少旧校验的情况。
