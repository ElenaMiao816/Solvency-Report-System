## 通用修复

1. 保持 VLM 读取金额。对具有明确文本表头和稳定表格网格的认可资产表，从缓存原图截取行次、项目、本期认可价值列，并为续页附上原始列标题。不解析或硬编码业务金额，也不依赖公司名称和固定页码。
2. 只使用人工确认范围内的页面。页面不连续、网格变化、表头歧义、跨入其他表或扫描件无法确认布局时，回退原图及表头上下文；不猜列号。遇到续页重复表头也不沿用旧列顺序。
3. 专列图片在首轮生成并缓存，失败重试不重复渲染。华汇每页只需一张精简图片；保留图片页数、尺寸和字节限制。
4. 检查模型返回的列口径，明确取账面、非认可、期初/上期列的结果触发失败指标重试，不允许凭相近数值过关。
5. 单页超时、接口异常、无效 metrics 响应均保留其他页结果并只重试失败页；持续失败保留请求覆盖阻断，不能伪装为真实未披露。
6. 补充“认可资产明细表”“非认可资产明细表”“认可负债明细表”的标题/边界识别。

## 验证范围

使用原 PDF 进行表格几何定位、图像生成和目视核对。自动测试使用模拟模型响应验证正常金额、错列校验、超时/接口错误/异常响应恢复、持续失败阻断、原图回退、缓存复用与既有案例兼容。未使用真实 API 密钥，未运行在线模型识别；这不等同于线上整份报告盲测。
