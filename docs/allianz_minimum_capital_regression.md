# 安联人寿最低资本提取修复

## 证据与诊断边界

- 输入：安联人寿2026Q1偿付能力季度报告摘要.pdf，33页。
- 最低资本表位于物理页32–33（印刷页30–31），共34个清单指标。
- 物理页32标注单位“元”；续页33没有重新标单位。只能取“本季度数”列。
- 本季度量化风险最低资本2,122,955,098.71元，控制风险最低资本4,029,851.39元，附加资本横杠按规则为0，最低资本2,126,984,950.10元，三项合计相符。
- 截图明确显示MINIMUM_CAPITAL:REQUEST_COVERAGE失败；这表示请求未完成，不能据此认定指标未披露。
- 未取得截图对应运行的请求日志，无法区分当时是超时、网络异常还是无效响应。代码可确定的问题是最低资本未启用轻量响应，全部34指标一次返回，失败后整表重复，未隔离指标批次。

## 修复

- 最低资本使用精简目标定义与稀疏响应，每次最多12个目标指标。
- 指标分批但保留已确认PDF页的上下文，继续遵守原图片页数/体积限制，共用一次渲染缓存；不把续页从单位说明页单独切走。
- 超时、连接异常、接口错误或无效metrics结构保留成功批次，只重试失败指标批次；保持原最多2次请求机会和90秒单次超时设置。
- 最终未完成的请求仍阻断Step3，门槛说明保留具体错误。不把请求失败转换为已确认未披露，不修改或放宽业务校验。
- 页面重试提示由“超时表”改为“失败请求批次”，兼容非超时错误。

## 回归范围

`tests/test_minimum_capital_chunks.py`逐项覆盖34个本季度披露值、元转万元、横杠归零、最低资本勾稽、三种错误的局部重试、永久失败保留成功结果且阻断门槛、单次尝试限制及真实PDF渲染。

接口返回由人工核对过原PDF的夹具模拟，不调用付费接口；这是流程回归，不代表在线模型准确率或在线服务已恢复。原PDF和已有下载文件均不改写。
