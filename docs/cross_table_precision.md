# 跨表一致性精度容差

修复前按标准值保留6位小数后严格判等。用户截图中北大方正的两组值分别为129138.041881/129138.041882、137622.411233/137622.411234，差异均仅0.000001，仍被误报为跨表冲突。

新规则针对同一指标语义键、相同标准单位的已披露数值：

- 金额最大值与最小值之差不超过1元的等值金额可通过，例如万元口径为0.0001万元，亿元口径为0.00000001亿元。不是按余额百分比放宽。
- 数量要求一致；百分比及其他无量纲值只允许0.000001标准数值的精度差异（百分比单位下为百分点）。
- 加入有上限的浮点边界误差保护。单位不一致、非有限数或超出容差仍失败。
- 校验明细记录实际值、最大差额、容差和判定说明，原始披露值及标准值不改写，不求平均，不覆盖其中一个来源。

应用范围：新提取校验、已有会话结果展示/下载、旧Step2文件上传时的跨表冲突复核。只重新判断可由至少两条记录支持的跨表一致性条目；其他失败（请求覆盖、期间、证据、必需目标、勾稽等）完整保留。证据不足的历史冲突不自动清除。

回归使用用户截图数值与边界构造数据，不依赖模型重跑。包括精度通过、超阈值拒绝、币值单位换算、百分比/数量、多来源最大差额、旧文件兼容及原数值不变。
