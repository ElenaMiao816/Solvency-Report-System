# 五份填报清单与标准窄表规则

本次目标来源为用户提供的五份“指标填报清单.xlsx”。原始文件不修改。
可审计的逐行映射保存在 `config/solvency_filing_checklists.json`，包含来源文件、工作表、Excel 行号、业务行次、原始名称、标准名称和指标编码。

| 来源清单 | 填报条目 |
| --- | ---: |
| 偿付能力充足率指标 | 15 |
| 实际资本明细 | 30 |
| 最低资本明细 | 34 |
| 主要经营指标 | 29 |
| 认可资产指标 | 49 |

共 157 个来源条目，对应 147 个不同指标编码。同一个指标在不同报表出现时复用编码；不同含义的同名指标不能合并。
主要经营指标中的四个分组标题不作为填报指标；“前五大保险产品”是文本指标。
另外保留两个独立的近三年平均投资收益率目标：`THREE_YEAR_AVG_INVESTMENT_RETURN`（近三年平均投资收益率）、`THREE_YEAR_AVG_COMPREHENSIVE_INVESTMENT_RETURN`（近三年平均综合投资收益率），期间口径均为“本季度”。“近三年平均”体现在指标名称和编码，数值采用本季度报告披露的近三年平均值，不自行对单年收益率求平均；兼容旧 Step2 文件中的收益率编码与近三年语义标记，转换后期间口径为“本季度”。
默认保留原有 35 个派生计算指标，共 184 个目标（149 个披露指标）。可下载系统目标表，在“启用”列关闭不需要的指标。

## 匹配与口径

- VLM v2 的五张表按清单编码提取，并携带来源标签及业务行次作为辨别上下文；近三年投资收益率功能保持独立。
- 已有 VLM v2 结果直接按标准编码转换，不再对标签二次模糊匹配。
- 旧版按表导出的工作簿根据来源表、标签和行次匹配，无法唯一确认时不猜测。
- 主要经营指标“净资产”与实际资本表“财务报表净资产”分别编码；各级资本的超限额扣除、附加资本各组成项、考虑特征系数前后的最低资本分别编码。
- 认可资产采用认可价值，不使用账面价值或非认可价值代替。
- 默认目标须保留本季度记录；近三年平均、预测和累计口径不能代替本季度值。

## 输出状态

标准窄表增加“披露状态”，原有字段顺序不变，避免破坏公式数值列引用。

| 状态 | 数值处理 |
| --- | --- |
| 已披露 | 保留标准化数值或文本 |
| 已披露为0 | 原表已有指标的横杠和数字 0 统一填数值 0，保留原始披露值 |
| 不适用 | 数值留空，保留原文与状态 |
| 未披露 | Step2 无对应本季度指标时仍输出该目标行，预览及 Excel 数值单元格填写“未披露”；内部计算保留缺失值，不参与运算 |
| 已计算 | 依赖满足时计算 |
| 无法计算 | 派生指标依赖不足，数值留空，不把缺失当 0 |

这里“未披露”表示当前 Step2 数据未提供对应指标，不等同于已核实 PDF 全文没有披露。补提取成功后可重新标准化。
所有补齐的目标行继承公司、同业分类和报告期。明确不适用不能被缺失占位覆盖；有有效值时优先保留有效值，不同来源冲突值仍保留供核验。

## 使用

重新启动或刷新系统后，Step3 下载的新默认目标表包含指标编码、目标表 ID、来源清单与填报规则。
现有 Step2 文件可直接重新标准化以补齐未披露行；要实际提取新增指标，需重新运行 Step2。旧的已生成窄表不会自动改写。
